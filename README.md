This is a simple command-line number guessing game written in Python. 

The computer randomly selects a number between 1 and 50, and the player must guess that number in as few attempts as possible!
After each guess, the program provides a hint until the number is not equal:

"Enter higher number" if the guess is low.

"Enter lower number" if the guess is high.

The game ends when the player guesses the number correctly. The program displays the total number of attempts.

## How to run
1. Ensure you have Python installed on your system.
2. Copy the code above into a file named game.py.
3. Open your terminal or command prompt.
4. Run the game using the command: python game.py

Start guessing!
